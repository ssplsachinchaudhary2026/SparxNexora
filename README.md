# Sparx Nexora — Expanded 3D Company Website

This version extends the existing Sparx Nexora 3D ASP.NET Core MVC website without replacing its visual identity.

## Added
- Detailed Services page
- Detailed Technology Stack page
- Industries / Solutions page
- Full How We Work process
- Portfolio / sample case studies
- Detailed About page
- FAQ page
- Contact page with requirement form
- Privacy Policy
- Terms & Conditions
- Cookie Policy
- Expanded footer/navigation
- Technology and trust sections
- Local SVG visual assets
- Animated `sparx-motion.gif`
- Existing Three.js background preserved
- WhatsApp CTA: +91 93688 50493
- SMTP contact email support via appsettings.json

## Important trust rule
The website does not invent customer counts, client logos, testimonials, awards or performance results. Replace clearly marked placeholders with verified company information before publishing.

## Run
```bash
dotnet restore
dotnet run
```

Configure `appsettings.json` for SMTP email. Use a Gmail App Password if Gmail is used.
